# 🎫 What is a Ticketing System?



---

## Definition

A **ticketing system** is software that converts every user complaint, request or incident into a **ticket** - a unique record with an ID number that tracks the issue through its entire lifecycle until it is resolved and closed.

---

## Why It Is Used

| Reason | Explanation |
|--------|-------------|
| Track every issue | Nothing gets lost - every request has a record |
| Prioritise work | Critical issues handled before low priority ones |
| Accountability | Every ticket is assigned to a specific technician |
| Communication | User is kept updated on their issue status |
| Reporting | Management can see how many tickets were resolved and how fast |
