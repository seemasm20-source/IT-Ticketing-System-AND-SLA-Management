# 📋 Key Components of a Ticket





## Ticket Fields

| Field | Description | Example |
|-------|-------------|--------|
| **Ticket ID** | Unique reference number automatically assigned | INC-00452 |
| **Requestor** | The user who raised the ticket | Sarah Jones - HR |
| **Category** | Type of issue | Software |
| **Priority** | Urgency level - determines response time | High |
| **Assigned To** | Technician responsible for resolving it | John Smith - IT Support |
| **Status** | Current state in the ticket lifecycle | In Progress |
| **Description** | Full details of the issue | "Outlook will not open since this morning" |
| **Created Date** | When the ticket was raised | 07/09/2026 09:15 |
| **Resolution** | What was done to fix the issue | Ran ScanPST - profile repaired |
