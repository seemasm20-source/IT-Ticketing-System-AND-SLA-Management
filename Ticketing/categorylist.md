# 📂 Category List

Categories help route tickets to the right team and track what types of issues are most common.



## Categories

| Category | Description | Example |
|----------|-------------|--------|
| **Hardware** | Physical device faults - PC, laptop, printer, monitor | Laptop screen broken. Printer not printing. PC will not power on. |
| **Software** | Application errors, crashes, installation or licence issues | Outlook will not open. Teams crashing. Cannot install software. |
| **Network** | Connectivity issues - no internet, VPN, Wi-Fi, shared drives | Cannot connect to VPN. No internet access. Shared drive not accessible. |
| **Security** | Compromised accounts, suspicious activity, malware, phishing | Phishing email received. Ransomware detected. Unusual login activity. |
| **Access Request** | Requests to grant or remove access to systems or files | New user needs access to HR shared drive. M365 licence needed. |
